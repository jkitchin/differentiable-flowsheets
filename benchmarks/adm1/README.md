# ADM1 steady-state verification case (published reference)

`report_steady_state.json` is Section 7 of Rosen & Jeppsson, *Aspects on
ADM1 implementation within the BSM2 framework* (Lund University,
TEIE-7224, 2006): the steady-state outputs (13 significant digits) of the
BSM2 ADM1 implementation for its verification influent, transcribed by
hand. `benchmarks/watertap/compare_adm1.py` compares difflow_water's
`anaerobic_digester` with it and with WaterTAP's ADM1 example. A hand-run
cross-check, not a test.
