CLOSED: [2025-12-16 Tue 18:38]

- [X]  1. CSTR (src/difflow/units/cstr.py)

  - Arbitrary molar density (line 145-149): Hard-coded total_molar / 50.0 assumes 50 mol/m³ - fails for gases (~40 mol/m³ at STP) or dense liquids
  - Phase assumption: Always uses phase="liquid" for enthalpy - breaks if reaction produces gases
  - Adiabatic damping: Hard-coded 0.3 damping factor may be too aggressive/conservative depending on problem scale
  - Zero inlet flow: Conversion calculation divides by inlet flow with no guard

- [X]  2. Flash Separator (src/difflow/units/flash.py)

  - Phase boundary discontinuity: Sharp transitions at bubble/dew points cause discontinuous derivatives
  - K-value extremes: No bounds checking - can become >100 near critical point, breaking Rachford-Rice
  - Unused arguments: bubble_check and dew_check passed to solver but never used
  - Composition normalization: May sum to 0.99 or 1.01 for multicomponent systems

- [X]  3. Heat Exchangers (src/difflow/units/heat_exchanger.py)

  - LMTD singularity: When ΔT₁ ≈ ΔT₂, log term ill-conditioned; no handling for ΔT = 0
  - Temperature crossing: No check for T_hot_in ≤ T_cold_in (unphysical)
  - Effectiveness Cr=1 edge case: Can divide by near-zero when heat capacity rates equal

- [X]  4. Distillation (src/difflow/units/distillation.py)

  - Arbitrary temperature profile: Hard-coded ±20K from feed - wrong for cryogenic/high-pressure systems
  - Fenske singularity: When α_LK ≈ 1 (close-boiling), N_min → ∞ with no warning
  - Hard-coded initial guess: T range 380-340K fails for non-ambient systems
  - Gilliland singularity: Y → 0.999 causes N → huge values

- [X]  5. PFR (src/difflow/units/pfr.py)

  - Same molar density issue as CSTR
  - RK4 flow clipping: Post-hoc jnp.maximum(F, 0) corrupts the ODE solution
  - Ideal gas units: R in J/(mol·K) but no unit validation for pressure
  - Hard-coded minimum pressure: 1 Pa minimum fails for vacuum systems

- [X]  6. LLE (src/difflow/units/lle.py)

  - Python for-loop: Activity coefficient computation uses Python loop instead of vmap - breaks autodiff
  - Hard-coded z=10: Coordination number should vary by system
  - Kremser E≈1 singularity: Arbitrary 1e-6 threshold
  - No shooting method: Counter-current model doesn't properly satisfy boundary conditions

- [X]  7. Bioreactors (src/difflow_bio/units/bioreactors.py)

  - Monod 0/0: When K_s → 0 and S → 0 simultaneously
  - Exception-based dispatch: Using try/except for kinetics signature - breaks JAX JIT
  - Euler integration: O(dt) error accumulates over long fed-batch runs
  - Hard-coded pseudo-time: dt=0.5 in fixed-point iteration may not converge

- [X]  8. Numerical Solvers (src/difflow/solvers.py)

  - No convergence check: Newton solver runs fixed iterations regardless of convergence
  - Arbitrary regularization: 1e-12 regularization is problem-dependent
  - Rachford-Rice bounds: Clipping to [0.001, 0.999] hides phase boundary failures
